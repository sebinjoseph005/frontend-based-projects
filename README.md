# Facebook UI Clone

This project is a simple clone of Facebook's login and signup page, created using HTML,CSS and javascript. The goal of this project was to improve my frontend development skills by replicating a real-world website layout.

## What I Learned 🏆

- **HTML & CSS Structuring**: I improved my understanding of layout structuring using `div`s, flexbox, and grid.
- **CSS Styling**: I learned how to style forms, buttons, and text to closely match a real-world website.
- **Javascript-I learned the basics of java script throught this too project by understanding its concepts.
- **Positioning Elements**: I practiced absolute and relative positioning to align elements properly.
- **Form Elements**: I gained experience with input fields, radio buttons, and dropdowns.
